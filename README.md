# Full-Stack MERN E-Commerce App (TypeScript)

A modern, responsive e-commerce platform built with the MERN stack and TypeScript.

## Live Demo
- **Frontend:** [https://fullstack-ecommerce-app-alpha.vercel.app/](https://fullstack-ecommerce-app-alpha.vercel.app/)
- **Backend API:** [https://ecommerce-backend-ts-1f17.onrender.com](https://ecommerce-backend-ts-1f17.onrender.com)

## Key Features
* **User Authentication:** Secure Login & Signup using JWT.
* **Product Management:** Admin can add, edit, and delete products.
* **Shopping Cart:** Add/Remove items with real-time price calculation.
* **Responsive Design:** Optimized for Mobile, Tablet, and Desktop.
* **Cloud Storage:** Image uploads handled via Cloudinary.
* **Database:** MongoDB Atlas for persistent storage.

## Tech Stack
- **Frontend:** Next.js 15, Tailwind CSS, Redux Toolkit
- **Backend:** Node.js, Express.js, TypeScript
- **Database:** MongoDB
- **Hosting:** Vercel (Frontend), Render (Backend)
